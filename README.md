# MadaChoice V3

V3 est une refonte visuelle inspirée de l'image de référence fournie dans la conversation.

## Tester
Ouvre `index.html`.

## Avant publication
1. Remplace `https://example.com/` par ton vrai domaine.
2. Remplace les liens d'affiliation `#` par de vrais liens partenaires.
3. Complète les pages légales.
4. Ajoute des images et contenus originaux.
5. Mets à jour le sitemap après ajout d'URL.

L'image de référence est conservée dans `assets/theme-reference.jpg`.
